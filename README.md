# تطبيق تتبع تجارة السيارات

تطبيق ويب (PWA) لشريكين يشترون ويبيعون السيارات — يسجل كل سيارة، مصاريفها،
بيعها (نقد أو تقسيط)، التبديل بسيارة بسيارة (بسلسلة كاملة)، الديون بين
الشريكين، ويحسب الربح تلقائياً. مبني بالكامل على Cloudflare (Workers + D1 + R2).

## المكدّس التقني

- **Cloudflare Workers** (مع Static Assets) — يستضيف الواجهة والـAPI ومهمة
  النسخ الاحتياطي اليومية بمشروع واحد
- **Hono** — راوتر الـAPI
- **D1** — قاعدة بيانات SQLite مشتركة
- **R2** — تخزين صور السيارات + نسخ احتياطي يومي (JSON)
- **Web Push (VAPID)** — إشعارات الأقساط المتأخرة على الموبايل

## الإعداد لأول مرة

### 1. المتطلبات
- Node.js (نسخة LTS)
- حساب Cloudflare (مجاني كافي للبداية)

### 2. التثبيت

```bash
npm install
```

### 3. تسجيل الدخول لـ Cloudflare

```bash
npx wrangler login
```

### 4. إنشاء قاعدة البيانات وحاوية التخزين

```bash
npx wrangler d1 create car-flip-tracker-db
npx wrangler r2 bucket create car-flip-tracker-storage
```

انسخ الـ `database_id` الذي يطبعه الأمر الأول والصقه في [wrangler.jsonc](wrangler.jsonc)
مكان `REPLACE_WITH_D1_DATABASE_ID`.

### 5. تطبيق قاعدة البيانات محلياً

```bash
npm run db:migrate:local
```

### 6. إنشاء الحسابات

ما تحتاج أي أمر طرفية لهذا. أول ما تفتح التطبيق (محلياً أو بعد النشر)
راح يظهر لك معالج إعداد لمرة وحدة — تدخل فيه اسم التجارة واسمك وتنشئ
حسابك كأول شريك. بعدها تكدر تضيف بقية الشركاء (اثنين أو أكثر، ما فيه حد)
من داخل التطبيق: **الإعدادات → إدارة الشركاء**، ومن نفس الشاشة تعدّل نسبة
كل شريك من الربح، تعطّل شريك ترك التجارة (بدون ما يضيع سجله التاريخي)،
أو تسوي إعادة تعيين كلمة مرور لشريك ثاني.

عدد الشركاء ونسبهم وأسماؤهم كلها بيانات داخل قاعدة البيانات، مو مكتوبة
بالكود — يعني نفس الكود هذا تكدر تنشره لأي مجموعة شركاء جديدة (نشر منفصل
لكل زبون) وهم يسوّون إعدادهم الخاص من نفس المعالج بدون أي تعديل بالكود.

> **إعادة تعيين كلمة مرور بدون CLI:** أي شريك مسجّل دخول يكدر يغيّر كلمة
> مرور أي شريك ثاني من شاشة "إدارة الشركاء" (ما فيه صلاحيات منفصلة، الفريق
> صغير وموثوق). سكربت `scripts/create-user.mjs` يبقى موجود فقط لحالة
> طارئة: آخر شريك فعّال نسى كلمة مروره ولا يوجد شريك ثاني مسجّل دخول
> يقدر يساعده.

### 7. إشعارات الأقساط المتأخرة (Web Push) — اختياري لكن موصى به

```bash
npx web-push generate-vapid-keys
```

- الصق `Public Key` في [wrangler.jsonc](wrangler.jsonc) مكان `REPLACE_WITH_VAPID_PUBLIC_KEY`
- انسخ [.dev.vars.example](.dev.vars.example) إلى ملف جديد اسمه `.dev.vars` (لا يُرفع لأي مكان)
  وضع فيه `Private Key` وبريدك الإلكتروني:

```
VAPID_PRIVATE_KEY=<private key>
VAPID_SUBJECT=mailto:you@example.com
```

بدون هذه الخطوة، التطبيق يشتغل طبيعي بس بدون إشعارات فعلية على الموبايل
(التنبيهات تبقى تظهر داخل التطبيق نفسه بالداشبورد وصفحة الأقساط).

## التشغيل محلياً للتجربة

```bash
npm run dev
```

يفتح على `http://localhost:8787`.

## النشر (Deploy) على Cloudflare

```bash
npm run db:migrate:remote
npx wrangler secret put VAPID_PRIVATE_KEY
npx wrangler secret put VAPID_SUBJECT
npm run deploy
```

بعد النشر، رابط التطبيق يكون شي مثل:
`https://car-flip-tracker.<اسمك>.workers.dev` — مجاني وبـ HTTPS، وقابل
للتثبيت كتطبيق على الموبايل مباشرة (Add to Home Screen).

بعد النشر، افتح الرابط — راح يظهر معالج الإعداد لأول مرة، أنشئ فيه حساب
الشريك الأول مباشرة على قاعدة البيانات الحقيقية، وأضف بقية الشركاء من
"الإعدادات → إدارة الشركاء".

لأي تحديث لاحق بالكود، فقط `npm run deploy` من جديد. لو غيّرت شكل قاعدة
البيانات، أنشئ ملف هجرة جديد بـ `migrations/000N_....sql` وطبّقه محلياً
(`npm run db:migrate:local`) ثم على الإنتاج (`npm run db:migrate:remote`).

## النسخ الاحتياطي

نسخة تلقائية كل ليلة الساعة 12 منتصف الليل بتوقيت العراق (21:00 UTC —
عدّلها بـ `triggers.crons` داخل [wrangler.jsonc](wrangler.jsonc) لو تريد
توقيت مختلف) تُحفظ بصيغة JSON داخل R2، وتحتفظ بآخر 30 نسخة. ما تحتاج تسوي
شي، تصير لحالها.

**استعادة نسخة احتياطية** إجراء يدوي نادر: نزّل ملف JSON من R2
(`npx wrangler r2 object get car-flip-tracker-storage/backups/<الملف> --file backup.json`)
وراجعه، ثم أعد إدخال البيانات المطلوبة عبر أوامر `wrangler d1 execute`.

## بنية المشروع

```
src/            كود الـAPI (Hono) — routes/ lib/ middleware/
migrations/     ملفات SQL لقاعدة البيانات
public/         الواجهة (HTML/CSS/JS عادي، بدون build step) — عربي بالكامل RTL
scripts/        أدوات مساعدة (إنشاء حساب، توليد أيقونات)
```
